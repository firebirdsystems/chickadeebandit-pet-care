# Pet Care

A [Chickadee Bandit](http://chickadeebandit.com) app.

Track pet care activities — feeding, medication, potty breaks, walks, and anything else you configure. Color-coded urgency shows when each activity is due. One tap to log it.

## Features

- Configure any care activities per pet with custom intervals
- Color-coded urgency: green (on track), amber (due soon), red (overdue)
- One-tap logging with optional notes
- Full care history per pet and activity
- Supports multiple pets

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-pet-care/releases/latest/download/bundle.json
```
